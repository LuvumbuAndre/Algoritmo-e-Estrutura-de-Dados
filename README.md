# Algoritmo-e-Estrutura-de-Dados
Repositório académico da disciplina de Algoritmos e Estruturas de Dados I, contendo projectos em Java, códigos-fonte, relatórios e apresentações. Inclui o Sistema de Gestão de Viagens e Passageiros, com implementação de Tabelas de Espalhamento (Hash Tables), tratamento de colisões e operações de gestão de dados.
